## 2. 逐条对照

### 3.1 Release 不必要开销
- 计数器：`PerfProbe.a5Seq` 为 `by lazy`，Release 下 `nextSeq()` 在守卫后直接返回 0，惰性块不执行。
- 字符串：所有 `A5/…` 文本拼接移入 `if (!BuildConfig.DEBUG) return` 之后（a5/a5Finally 内部）；
  调用点仅传 Int/Boolean 参数。既有 A-3 常量字符串探针（`Pager/scrollStart` 等）无拼接成本，未改动。
- 业务行为：`tabGuard.begin/end`、`alignRouteToPager` 调用序与条件完全不变。

### 3.2 ADB 环境恢复
- 实验前读取 `settings get system min/peak_refresh_rate` 保存于 run_info.json（*_before）。
- finally 中恢复原值；恢复命令 returncode≠0 时写入 restore_failures 明确报告；恢复后复读记录（*_after）。
- 不假定原值 60/120（实测 Redmi 原值为 60/60，逐轮记录）。

### 3.3 ADB 命令失败检测
- 统一 `must()` 包装：returncode≠0 立即中止本轮，失败命令/退出码/stderr 尾部写入 run_info.json。
- 录屏进程 `wait()` 检查退出码；拉取后检查文件存在、size>0、头部含 ftyp（可读性）。
- logcat dump 检查 returncode 与非空；每轮独立目录 `raw/<scenario>_<hz>hz_r<rep>/`，已存在拒绝覆盖。

### 3.4 设备适配与坐标保护
- `DEVICES` 表按 `ro.product.model` 索引：V2352A（vivo：515/725/921 @2621）与
  2407FRK8EC（Redmi：503/703/885 @2493，uiautomator bounds 实测中心）。
- 启动核对 `wm size` 与表内分辨率；未知机型或分辨率不符即中止，不套用任何默认坐标。
- 实际坐标与设备信息写入 run_info.json。

### 3.5 点击间隔定义
- monotonic 时钟按计划时间点调度（场景定义间隔 150/200/250ms），每击记录
  plan_offset_ms / actual_offset_ms / **deviation_ms** / cmd_duration_ms。
- ADB tap 命令耗时（实测 52–109ms）单列；间隔以计划值描述、偏差如实呈现，
  **不表述为严格固定间隔**。
