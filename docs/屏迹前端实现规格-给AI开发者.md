# 屏迹 ScreenTrace 前端实现规格（给 AI 开发者）

Nov 12, 2026 · @zh

## 1. 项目背景与改造边界

本文件交给 AI 开发者，用来在不改动数据层的前提下，重做「屏迹」Android 应用的界面。目标是把现有的干净 Material 3 风格，升级为层次更清晰、信息更易读的版本；应用只供个人使用，不上架、不盈利。

**原项目**：[Sunbeam-5/ScreenTrace](https://github.com/Sunbeam-5/ScreenTrace)，Apache-2.0 协议，个人改造和自用均允许；保留 LICENSE 文件即可。

**应用做什么**：通过 Shizuku 读取系统 `usagestats`，在本地累积每天的屏幕使用时间，展示今日概览、趋势统计、日历热力图、应用排行。无账号、无广告、不联网。

**技术栈**

| 项目 | 取值 |
| --- | --- |
| 语言 | Kotlin 1.9.24 |
| UI | Jetpack Compose + Material 3 |
| 本地存储 | Room |
| 最低系统 | Android 8.0（API 26） |
| 构建 | JDK 17，Android SDK Platform 34，`./gradlew :app:assembleDebug` |
| 测试 | 174 个 JVM 单元测试，`./gradlew :app:testDebugUnitTest` |

**改造边界（必须遵守）**

- 只改视觉层：`theme/` 和 `uikit/` 目录，以及 `ui/` 下的页面布局代码。
- 不动数据与口径：`contract/`、Room 数据库、Shizuku 拉取与解析逻辑一律不改。
- 不新增网络权限，不接入任何统计 SDK。
- 「—」不等于 0：没有事件源时显示 `—`，沿用原项目这一规则，不要改成 0。
- 页面里不得直接写十六进制颜色，只能读 `LocalFreshPalette.current` 或 `MaterialTheme.colorScheme`（原项目的硬规定，由测试保护）。
- 每改完一块就跑一遍单元测试，尤其是 `FreshPaletteContrastTest` 和 `PaletteEngineTest`。

**本文件里的取值来源**：「原」表示取自原项目代码；「新」表示本次优化版设计稿里的新取值。设计稿是网页版示意，可在这里查看：[优化版界面预览](https://claude.ai/artifact/7sfBrH3KkWbopEwdWCPfwd)。

## 2. 设计原则与整体视觉方向

一句话定位：**柔和的雾蓝色调、大圆角卡片、数字优先**。像一张干净的仪表盘，让人一眼看到「今天用了多久、比平时多还是少」。

1. **数字是主角**：时长用大字号等宽数字，单位（小时、分钟、次）用小字号、淑色跟在后面。
2. **颜色表达状态，而不是装饰**：同一个主色的深浅色阶表示层级和多少；「超目标」用唯一的暖色（珊瑚橘）提示；其余地方不引入新色相。
3. **层次来自留白和轻阴影**：卡片不描边，靠背景渐变、白卡和很淡的阴影拉开层次。
4. **安静的动效**：只在进场、选中和切换时动，不做循环动画。
5. **可读性优先**：次要文字不小于 12sp，正文对比度≥ 4.5:1；不能只靠颜色区分信息，要有文字、位置或图标作辅助。

**和原项目的关系**：保留「一个主色派生全套色阶」、24dp 大圆角、悬浮胶囊导航、九套主题×深浅色。变化集中在：背景渐变、卡片轻阴影、圆环双层和渐变描边、字体、热力日历、应用构成列表。

**明确不要做的**：不加插画、不加渐变彩虹色、不用表情符号当图标、不用拟物阴影、不把卡片做成左侧带色条。

## 3. 设计令牌

设计稿按 390 宽的手机画板绘制，**设计稿里的 1px 对应 Compose 里的 1dp，字号 1px 对应 1sp**。下面以「雾蓝」主题（`ThemeVariant.MIST`）为例，其他八套主题仍由原项目的 `derivePalette` 按同比例派生，不要手写。

| 语义 | 取值 | 来源 | 用在哪里 |
| --- | --- | --- | --- |

| 副容器 tonalB | `#CECCE6` | 原 | 「解锁」「最久的一天」等淑紫卡 |
| 导航底色 navLight | `#C5DCE7` | 原 | 导航胶囊（新版改为白色 80% 透明，见 4.6） |
| 页面背景 | `#F6F8F9` | 原 | 渐变的最终底色 |
| 卡片 surface | `#FFFFFF` | 原 | 白卡 |
| 主文字 | `#14262F` | 新 | 标题、数字（原为 `#1D322B`） |
| 次要文字 | `#4F6672` | 新 | 标签、图表轴（原为 `#556A5F`） |
| 淑紫卡上的字 | `#3B4463` | 新 | 仅用在 tonalB 卡上 |
| 浅蓝卡上的字 | `#2F5265` | 新 | 仅用在 tonalA 卡上 |
| 圆环轨道 / 开关底 | `#E4EEF3` / `#EAF2F6` | 新 | 由 seed 与白混合得到，原实现为 `seed.mix(White, 0.92)` |

**图表色阶**（同一主色由深到浅，对应原项目的 chart1–chart5）：`#2C576D` → `#467790` → `#7FA6BA` → `#A9C5D2` → `#D3E1E8`。

**热力日历 4 档**（由少到多）：`#DCE9EF` → `#B7D0DC` → `#7FA6BA` → `#2C576D`，无记录为透明。最深一档上的字用白色，其余用主文字色。

**深色模式**：继续走 `derivePalette(..., darkTheme = true)`，不要单独手写。设计稿只给了浅色；深色下的渐变背景建议从 `background` 渐变到 `background.mix(White, 0.04)`，轮廓和阴影改为更低透明度。

> 设计稿里「新」标记的颜色我**没有逐一用对比度公式核算过**。实现时请用项目里现成的 `contrastRatio()` 验证：正文≥ 4.5:1，大号文字≥ 3:1，不达标就加深文字色。

### 3.2 字体与字号

| 样式 | 字体 | 字号 / 行高 | 字重 | 其他 | 原字号 |

| 页面标题 | 思源黑体 / Noto Sans SC | 32 / 38 | Bold | 字距 -0.5 | 24 |
| 圆环中心大数字 | Manrope | 46 / 54 | ExtraBold (800) | 字距 -1.8，等宽数字 | 40 |
| 统计页大数字 | Manrope | 40 / 48 | ExtraBold | 字距 -1.2，等宽数字 | — |
| 指标卡数字 | Manrope | 30 / 36（统计卡 28 / 34） | ExtraBold | 字距 -0.5 | 26 |
| 卡片标题 | Noto Sans SC | 18 / 24 | Bold | — | 18 |
| 正文 / 列表项 | Noto Sans SC | 14 / 20 | Medium | — | 14 |
| 数字型行内数据 | Manrope + Noto Sans SC | 14–15 | SemiBold / Bold | 等宽数字 | — |
| 标签 / 轴 / 辅助行 | Noto Sans SC | 12–13 | Medium | — | 12 |

- 「数字 + 小单位」的排版和原项目一致（如 `11 小时 57 分钟`，数字大、单位小且淑）。

| 项目 | 取值 |
| --- | --- |
| 白色大卡圆角 | 28dp（原 24dp） |
| 双色 tonal 卡圆角 | 24dp |
| 内部小块（选中日详情、按钮） | 18dp |
| 图标底块 | 12–20dp |

| 基础间距单位 | 4dp（沿用原规则） |
| 页面左右边距 | 16dp（标题行为 20dp） |
| 卡片内边距 | 白卡 20dp，tonal 卡 16dp |
| 卡片之间的间隔 | 12dp |

Compose 里阴影用 `Modifier.shadow(elevation = 6.dp, shape = ..., ambientColor = ..., spotColor = ...)`，把阴影颜色改成主色的低透明度版本，而不是默认的黑色。两层阴影无法精确复现，近似即可。

### 3.4 页面背景渐变

竖向渐变，从顶部到底部：`#D6E7EF`（0%）→ `#E9F1F5`（18%）→ `#F4F7F9`（40% 到底）。用 `Brush.verticalGradient(colorStops = ...)` 并跟随滚动内容固定在屏幕后面（不要随内容滚走）。

## 4. 通用组件规格

下面每个组件都标注了对应的原项目文件，尺寸单位一律是 dp / sp。原项目已有的交互逻辑、读屏描述、容器变换动画都要保留，只改外观。

### 4.1 白卡与 tonal 卡

- **白卡**（今日圆环卡、应用构成卡、趋势卡、日历卡）：背景 `surface`，圆角 28，内边距 20，两层轻阴影，不描边。
- **tonal 卡**（指标卡、最久/最少的一天）：左卡 `secondaryContainer`（淑紫），右卡 `primaryContainer`（浅蓝），圆角 24，内边距 16，无阴影，两卡等宽、间隔 12。
- **可下钻指标卡**（今日页的「解锁」「通知打扰」）：最小高度 124。左上是 34 × 34、圆角 12、白色 55% 透明的图标底块（20dp 线性图标），右上是 18dp 箭头；下面依次是标签 13sp、数字 30sp + 单位 13sp、补充行 12sp。整张卡可点，沿用原有的 ripple 和「标签 + 当前值 + 查看详情」读屏描述。
- **统计型 tonal 卡**（最久/最少/低于阈值）：不可点、没有图标和箭头，最小高度 104，数字 28sp。
- 文件：`uikit/MetricCard.kt`。

### 4.2 圆环（今日页主视觉）

文件：`uikit/RingProgress.kt`。参数 `progress` 仍由调用方按 `使用分钟 / 目标分钟` 传入，**现在允许超过 1，上限 2**。

| 项目 | 原实现 | 新设计 |
| --- | --- | --- |
| 尺寸 | 184 | 184（不变） |
| 线宽 | 9，圆头 | 14，圆头 |
| 轨道色 | `track` | `#E4EEF3`（仍读 palette.track） |
| 第一圈 | 单色 primary | 线性渐变 `#2C576D` → `#6FA3BC`（左上到右下） |
| 超过目标后 | 保持满圈 | 第二圈：从 12 点位置起、转角 `(progress - 1) × 360°`，用更深的主色（`#17384A`，即 primary 向黑混合 35%）叠在第一圈上 |
| 中心文字 | 仅 `H:MM` | 顶部「今日亮屏」12sp，中间 `H:MM` 46sp，底部「目标 4:00」12sp |

- 设计稿示例：目标 4:00、已用 5:42，第二圈约 153°。
- 重要提醒：原项目的代码注释专门解释过，之前圈里塞三行字在真机上显得拥挤，所以去掉了 caption。设计稿里的线宽加粗后内径仍有 156，应该放得下，但**没在真机验证过**。如果真机上觉得挤，就去掉顶部的「今日亮屏」，只保留数字和底部目标。
- 进场动画见第 6 节。
- 圆环下方两个标签见 4.3；再下面是一条分隔线（1dp，`#E8EFF3`）和「近 7 天迷你柱」：7 个宽 14、高度不超过 36 的圆角柱（圆角 7），今天用主色、其余用 `#C5DCE7`，柱下写周几（12sp，今天加粗），右上角写「日均 X小时Y分」。

### 4.3 状态标签（Chip）

高 28，完全圆角，水平内边距 10，12sp SemiBold。三种用法：

| 用途 | 底色 | 字色 | 内容示例 |
| --- | --- | --- | --- |
| 超出目标 | `#FBE9E1` | `#9A4121` | 超出目标 1小时1分 |
| 中性对比 | `#EAF2F6` | `#2F5265` | ↗ 较昨日 12 分钟（前面带 12dp 箭头图标） |
| 下降 | `#DDEFE8` | `#1F6B4F` | ↘ 较上周 24 分钟 |

箭头方向代表增减，颜色只是辅助，不要仅靠颜色区分上升与下降。原项目里的 `CompareLine` 对应文案仍用（例如「较昨日增加 12 分钟」），没有对比数据时**整个标签不显示**，不要再写「暂无上一周期数据」。

### 4.4 应用构成（色带 + 列表）

文件：`uikit/SegmentedBar.kt` 与 `ui/TodayScreen.kt`。仍然是「前 4 个应用 + 其他」。

- **色带**：高 14，每段圆角 7，段间距 3，按分钟数分配权重，颜色依次是图表色阶 1→5。
- **列表行**（高 34，横向 12 间距，五行）：应用图标 28 × 28（圆角 9） → 名称 14sp Medium（占满剩余宽度） → 时长 14sp SemiBold 等宽数字 → 百分比 12sp，右对齐、宽 36。
- **图标和色带的对应**：设计稿用「彩色字母块」占位。实际要用原项目的真实应用图标（`uikit/AppIcon.kt`），那么在每行最左侧加一个 8dp 圆点，颜色与色带对应段一致。
- **日间/夜间**：上方一行左侧是「太阳图标 + 日间 72%」，右侧是「28% 夜间 + 月亮图标」（13sp，百分数加粗用主文字色，图标为 16dp 线性图标，太阳用主色、月亮用 #5B5A8C），下方一条高 10、圆角 5、段间距 3 的双色条（日间用主色，夜间用 tonalB）。
- **「查看全部应用」按钮**：高 48，圆角 18，底 `#E6EFF4`，文字和 16dp 箭头用主色，14sp Bold。原项目的 `transformSource` 容器变换起点必须保留在这个按钮上。

### 4.5 柱状图（统计页）

文件：`uikit/MetricBarChart.kt` / `uikit/CapsuleBarChart.kt`，读数逻辑在 `TrendChartMath.kt`（有测试，不要改数学部分）。

- 绘图区高 150；左侧纵轴标签 12sp，列三个刻度（0、一半、最大值），线宽 1、颜色 `#E8EFF3`。
- 平均线：主色 55% 透明度、线宽 1.5、虚线，图例写在图表下方（「┄┄ 日均 5小时31分」），**不要**再像原版那样把「平均」二字压在图里。
- 柱子：宽 18，顶部圆角 9，底部圆角 4；选中用主色，其余用 `#C5DCE7`。横轴标签 12sp，选中的加粗并用主文字色。
- **选中日详情面板放在图表上方**，不再用浮层气泡盖住柱子（原版的气泡会盖住相邻柱子）：底 `#F1F6F9`，圆角 18，内边距 12/14。第一行左侧「周六 · 11月7日」13sp，右侧总时长 18sp ExtraBold；第二行是最多三个应用的「小药丸」（白底、完全圆角、左侧 20dp 应用图标 + 12sp 时长）。
- 默认选中最后一天（今天）；点柱子切换。
- 30 天模式没有出设计稿，请按同一规则推导：柱宽按列数缩小到 6–8，横轴每 5 天显示一个标签，其余不变。

### 4.6 悬浮胶囊导航

文件：`uikit/FreshNavBar.kt`。**结构、尺寸、spring 展开动画、点击区域全部保留原实现**（52dp 图标槽、选中项展开到「图标 + 文字」、项间距 4、容器内边距 6），只换颜色和质感：

- 容器：白色，透明度 92%（设计稿的 80% + 模糊在 Compose 里不好复现，不要引入新的模糊库），1dp 描边（主色 10%），阴影 `0 10 30 rgba(20,38,47,.14)` 的近似值。
- 选中项：主色底、白字（14sp Bold）、图标 22；未选中项：透明底、主色图标。图标用线性图标：今日—房子、统计—三根柱、日历—日历。
- 位置：屏幕底部居中，距底 20dp，需要加上系统手势条的 inset。
- **注意原版的一个问题**：原项目截图里导航胶囊盖住了页面底部内容（如「查看全部应用」按钮）。每个可滚动页面的内容底部必须加 `contentPadding`：导航高度约 64 + 距底 20 + 系统 inset + 16。

### 4.7 分段控件（近 7 天/近 30 天、月视图/年视图）

文件：`uikit/SegmentedControl.kt`。高 44，内边距 4，完全圆角，底 `#EAF2F6`（设计稿里日历页用了 `#E3EDF2`，统一用 `#EAF2F6`）。选中滑块主色底、白字、14sp Bold；未选中文字 `#2F5265`。滑块在两个选项之间滑动，不要直接跳变。

### 4.8 热力月历

文件：`uikit/MonthCalendar.kt`、`uikit/HeatmapCalendar.kt`。

- 月份行：左右各一个 44 × 44 的圆形按钮（底 `#F1F6F9`，主色 20dp 箭头），中间「2026 年 11 月」18sp Bold。
- 星期行：12sp 次要文字，周一开始。
- 日期格：38 × 38，圆角 13，数字 Manrope 14sp 等宽，本月字重 SemiBold，行间距 4，7 列等分。
- **着色档位**：按当天使用时长与每日目标的比值分 4 档——≤ 100% 第 1 档、≤ 140% 第 2 档、≤ 175% 第 3 档、更高为第 4 档（设计稿用目标 4 小时算出的阈值，实际要读用户设置的目标）。第 4 档文字用白色。没有记录的日子不着色。
- 上个月/下个月的补位日：数字用次要文字色。设计稿里补位日也着了色；实现时**建议不着色**，只显示淑色数字，这样更干净。
- 今天：白色 2dp 间隔 + 主色 2dp 外环（向外扩 2–4dp）。
- 图例：卡片底部一行，左侧「少 □□□□ 多」（16dp 方块、圆角 6），右侧「○ 今天」。
- 点某一天的行为沿用原项目（跳转到该日详情），后续可改为底部弹出面板，不在本次范围。
- 年视图没有出设计稿，直接用同一个 4 档色阶、小格子、圆角按比例缩小即可。

### 4.9 页面顶栏

三个主页面共用。左侧是页面标题 32/38 Bold + 副标题 14/20（今日页写「11月12日 · 周四」，统计页写日期范围，日历页写「已记录 N 天」，颜色 `#3F5967`）；右侧两个圆按钮，44 × 44，底为白色 72% 透明，1dp 主色 10% 描边，22dp 线性图标（日历 = 选择日期范围、滑杆 = 设置）。

## 5. 三个主页面逐屏规格

通用规则：页面左右边距 16，卡片间隔 12，顶栏之下的内容从顶部约 100 处开始，整页可纵向滚动，底部留出导航的空间（见 4.6）。设计稿里的页面是固定高度的演示画板，实际代码用可滚动的 `Column` / `LazyColumn`。

数据绑定一律沿用原项目已有的类型（如 `TodayData`、`Summary`、`MetricDetail`）。我只读过 `TodayScreen.kt`，统计页、日历页的字段名没有逐个核对，以实际代码为准。

### 5.1 今日页（`ui/TodayScreen.kt`）

页面有两种口径：选中单日（`DateSelection.Day`）显示当天合计；选中区间显示日均。下面所有文案都要区分两种。

**由上至下三张卡，再加顶栏：**

1. **顶栏**：标题「今日」，副标题单日写「11月12日 · 周四」，区间写「11月6日 – 11月12日」。
2. **主视觉卡（白卡，居中对齐）**

   - 「最长连续 X」（`longestSessionMin`）：原版在圆环下方的一行小字。设计稿里为腾出空间没有放，建议把它放到标签行下方一行 12sp 次要文字，不要丢。
   - （可选）分隔线 + 「近 7 天迷你柱」：需要 7 天数据，若今日页的数据源里没有、又不想新增查询，就直接不做。统计页已有同样的数据，可以复用这部分的查询结果。

   - **数值和补充行规则全部沿用原项目**：没有事件源时数字显示「—」，补充行写「未采集到解锁事件 / 未采集到通知事件」；有事件源时通知卡补充行写「已查看 X 次」，解锁卡补充行为空。

**状态页**：加载骨架、错误重试、正在拉取（`PullingState`）、数据为空（`DataEmptyState`）仍然用原项目的组件和分支顺序（**有数据就画数据**，切换日期时不要闪一下骨架），只把卡片圆角、颜色、阴影换成新令牌。

## 6. 动效、无障碍与数据显示规则

### 6.1 动效

原项目已有导航胶囊的 spring 展开、页面进场（`uikit/PageEnter.kt`）和容器变换（`ContainerTransform.kt`），这些**全部保留、不要重写**。以下是新增的部分，统一放在 `uikit/Motion.kt`：

| 对象 | 动画 | 时长 / 曲线 | 触发 |
| --- | --- | --- | --- |
| 圆环与中心数字 | 用**一个**动画值从 0 到 `progress`；第一圈读 `min(p, 1)`，第二圈读 `max(p - 1, 0)`，中心数字同步按分钟滚动 | 900ms，`FastOutSlowInEasing` | 首次进入、切换日期 |
| 柱状图柱子 | 从高度 0 生长到目标高度，每根延迟 30ms | 500ms，`FastOutSlowInEasing` | 首次进入、切换 7/30 天 |
| 柱子选中态 | 颜色渐变 + 详情面板内容淡入淡出 | 150ms | 点柱子 |
| 分段控件滑块 | 水平滑动 | 250ms，`FastOutSlowInEasing` | 切换选项 |
| 热力月历切换月份 | 新一月淡入，带 8dp 水平位移 | 200ms | 点上一月/下一月 |
| 构成色带 | 各段宽度从 0 展开 | 500ms | 首次进入 |

- 所有动画只播一次，不做循环、呼吸、闪烁。
- 系统「移除动画」或动画时长缩放为 0 时（`Settings.Global.ANIMATOR_DURATION_SCALE == 0`），直接显示最终状态。
- 点柱子选中时触发一次轻触感（`LocalHapticFeedback`）。

### 6.2 无障碍

- **点击区域不小于 48 × 48dp**：顶栏的 44dp 圆按钮、月历的 44dp 箭头按钮要把点击区域扩大到 48（`minimumInteractiveComponentSize()`），视觉尺寸不变。
- 图标按钮必须有 `contentDescription`：选择日期范围、设置、上个月、下个月、导航三项（今日/统计/日历）。纯装饰图标传 `null`。
- 图表要有文字版：圆环读「今日亮屏 5小时42分，目标 4小时，已超出 1小时42分」；每根柱子读「11月7日，7小时12分」；热力格读「11月7日，7小时12分」，没有记录的读「11月8日，无记录」。
- **不能只靠颜色传递信息**：上升/下降有箭头和文字，超目标有文字标签，热力格有四档图例。
- 对比度：正文≥ 4.5:1，大号文字（18sp 以上加粗或 24sp 以上）≥ 3:1。新增颜色用 `contrastRatio()` 校验后再定稿（见第 3 节提示）。
- **字体放大**：在系统字体 1.3 倍、显示大小最大时，文字不被截断、卡片不重叠。卡片高度用 `heightIn(min = ...)`，不要写死高度；圆环中心数字设 `maxLines = 1`，超宽时自动缩小。

### 6.3 数据显示规则（沿用原项目，不要改）

1. **「—」不等于 0**：系统没有上报解锁/通知事件时显示「—」并带说明文字；只有确实有事件源且次数为 0 时才显示 0。
2. **时长格式**：统一用 `UsageCalculator.formatDuration` 和 `formatClock`，不要新写格式化函数。「数字 + 小单位」排版下，小时和分钟各自带单位。
3. **应用时长之和可能大于亮屏总时长**（含前台服务、画中画）。所以构成列表里的百分比**用显示的各项之和作分母**，不要用亮屏总时长，否则会出现超过 100% 的情况。百分比四舍五入，合计不强制等于 100%。
4. **目标为 0 或未设置**（`dailyGoalMin <= 0`）：圆环不显示进度、不显示「目标 H:MM」和「超出目标」标签。
5. **没有对比数据**：相关标签整个不显示，不要用假数字或占位文字。
6. **文案**：原项目的中文文案（如「解锁次数」「通知打扰」「已查看 X 次」「查看全部应用」）不要改。只有第 5.1 节明确列出的文案可以新增或删除。
