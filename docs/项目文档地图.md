## 4. 给下一个 AI 的开工顺序

1. 读需求文档 §5.2 / §5.3 / §5.7，再读规格 §3 / §4 / §7.2 / §7.3；**不要**拿 `给MiMo-UI视觉升级提示词.md` 当执行依据。
2. 跑 `./gradlew :app:testDebugUnitTest`（JDK 17），确认 **310 例全绿**；`assembleDebug` 能出包。
3. 按 Step 7 → 9 推进（Step 6 已完成），**每步一个提交**，提交信息写清 Step 编号；改 UI 不动 `contract/` 与 `data/` 业务逻辑、不硬编码颜色、不添加运行时依赖。
4. 每步真机看一眼再收工；深色模式与九套主题放到 Step 9 统一巡检。
5. 不修改 `README.md`；推送由负责人执行。
