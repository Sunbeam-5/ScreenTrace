# 人工手指验证清单（CR-30 A-1/A-2 真机观感验收）

> 目的：GPT 要求 adb input 注入数据不作最终体验依据，须真人手指操作验证。
> 设备：Redmi 2407FRK8EC + vivo V2352A 各过一遍；每台先默认 120Hz 全部场景，
> 再切 60Hz 复测 ★ 标注场景。每场景操作 ≥5 次，记录下表。

## 测试前准备（两台一致）

1. 电量 >50%，**拔掉充电线**（充电触发温控降频会干扰观感）。
2. 关闭后台大型应用；屏幕亮度固定一半；系统动画缩放保持默认（开发者选项三档均为 1x）。
3. 确认 App 数据量正常（今日页有真实数据）；记录两台各自的系统刷新率设置。
4. 手机平放桌面、坐姿、双手操作；每场景记录「操作人主观感受」即可，无需截屏。

## 场景清单

### S1 ★ 相邻 Tab 切换（今日 ↔ 统计）
- **操作**：今日页食指点底部「统计」→ 等动画完全停下 → 点「今日」。慢速 5 次 + 快速 5 次（间隔 0.3s 内连点）。
- **记录**：① 手指抬起瞬间有无顿挫；② 动画中途是否顺滑；③ 顶栏标题/导航高亮与动画是否同步；④ 观感 1–5 分。

### S2 ★★ 跨两页 Tab 切换（今日 ↔ 日历）——重点场景
- **操作**：今日 → 点「日历」→ 等停 → 点「今日」。5 次。
- **预期锚点**：Redmi 长帧 97–101ms 应为**轻微顿挫**；vivo 长帧 250ms 应为**明显一顿**。
  A-2 实验证明顿挫与动画无关——**卡顿应出现在手指抬起后的切换起点**，动画中途应顺滑。
- **记录**：① 顿挫位置（起点 / 中途 / 无）；② 程度（无 / 轻微 / 明显 / 严重）；③ 有无内容闪烁、
  空白一帧、景深缩放跳变；④ vivo 与 Redmi 哪台更明显；⑤ 观感 1–5 分。

### S3 ★ 连续快速点击
- **操作**：快速循环 统计→日历→今日 ×3 轮（间隔约 0.5s）；再乱序急促点击 10 次。
- **记录**：① 页面是否跟得上点击节奏；② 状态一致性（点的日历显日历、导航高亮正确）；
  ③ 动画互相打断是否残留中间态 / 错页 / 白屏；④ 观感 1–5 分。

### S4 ★★ 横滑切页——vivo 重点
- **操作**：内容区横滑 今日→统计→日历→反向滑回。5 次（快滑、慢拖各半）。
- **预期锚点**：Redmi 最顺（p99 ≤27ms）；**vivo 测量约 30% 掉帧、p50 18ms，预期有拖动抖动**。
- **记录**：① 跟手性（拖动是否即时）；② 松手惯性是否流畅；③ 滑动中抖动/掉帧感（vivo 重点）；
  ④ 景深缩放是否顺滑；⑤ 观感 1–5 分。

### S5 深浅色切换
- **操作**：设置 → 外观 → 深色模式开关来回切 3 次。
- **记录**：① 切换瞬间闪白/闪黑；② 壁纸取色过渡自然度；③ 内容抖动；④ 观感 1–5 分。

### S6 壁纸开关/更换
- **操作**：设置 → 外观 → 自定义壁纸：「恢复默认」→「选择图片」换一张，×2 组。
- **记录**：① 换图后全 App 背景更新是否即时；② 滚动/切 tab 时壁纸层是否稳定不闪；
  ③ 暗化/模糊调整是否平滑；④ 观感 1–5 分。

### S7 冷启动首屏（补充）
- **操作**：上滑划掉 App → 点图标冷启。3 次。
- **记录**：① 白屏/加载感时长主观值；② 内容是否分批闪烁出现；③ 观感 1–5 分。

### S8 日期切换（补充——数据加载路径）
- **操作**：今日页「选择日期」→ 昨天 → 回「今天」。3 次。
- **记录**：① 页面换值闪烁；② 等待感；③ 观感 1–5 分。
