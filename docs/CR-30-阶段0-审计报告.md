## 1. 当前架构图（文字版）

```
ScreenTraceApp（WorkManager 排程）
└─ AppContainer（手工依赖容器）
   ├─ SettingsStore（DataStore：deviceId/昵称/主题/目标/壁纸/合并账本旧档）
   ├─ DeviceDatabases（本机库 screentrace.db + 副本库 screentrace-dev-*.db，v8）
   ├─ IngestPipeline（拉取入库，同来源取大 + 事件 seq）
   ├─ PullCoordinator（Shizuku → UsageStats 降级，10 分钟节流）
   ├─ BackupRepository（导出/恢复 schema 6 + 归档 + legacy 只增）
   ├─ SyncManager（WebDAV；Google Drive 预留）
   ├─ DeviceOperations（切换/合并到本机 + 账本同事务）
   ├─ SourceArchive / SourceRebuild（CR-28 归档/重建/清洗，已冻结）
   └─ AppViewModel（四页状态 + 二级页 + 备份/同步/壁纸/主题）
        └─ AppNav（HorizontalPager 三主页面 + ContainerTransformOverlay + FreshNavBar）
```

分层：`contract`（UsageRepository/UsageCalculator 口径唯一出处）→ `data`（Room/解析/备份/同步）→ `ui`（四页 + 二级页）+ `uikit`（组件库）+ `theme`（PaletteEngine 九套 + 壁纸派生 + 动态取色）。

## 5. 限额删除影响清单

| 层 | 位置 | 处理 |

## 6. 提醒功能保留方案（周期总结提醒）

- **范围**：每周 + 每月总结提醒（双开关、默认关、默认 22:00）；周一提醒上一完整自然周、每月 1 日提醒上一完整自然月；删除一切使用干预提醒（本就未实装）。
- **实现**：WorkManager 周期任务（非精确）；`POST_NOTIFICATIONS` 开启时才申请；通知点击深链「日历 → 周期总结」对应周期；无有效数据不发；关闭/改时先取消旧排期；重启/更新/时区变更恢复（WorkManager 自带持久化 + 启动校对）。
- **状态机**：关闭 → 开启（无权限→引导）→ 开启（有权限→已排期）；同周期去重（`lastNotifiedPeriod` 持久化）。
- **数据**：`alertEnabled` 备份字段（BackupSettings）语义改为「提醒开关集合」或新增 `weeklyReminder/ monthlyReminder/time`——**属 DataStore 设置，不进 CR-28 数据表**，无数据库改动。

## 7. 主题状态机与颜色优先级

**现状三源**：九套预设 + 自定义种子色（`PaletteEngine.paletteFromSeed`）、壁纸派生色（`WallpaperPalette`，两模式：仅卡片/整套主题）、Android 12+ 动态取色（`dynamicColor`）。

**目标状态机（阶段 C）**：
```
颜色来源 = dynamicColor 开启 ? 系统动态取色
         : 壁纸启用且范围=整套主题 ? 壁纸派生（界面明确「由壁纸驱动」，九套选择置灰/隐藏）
         : 用户主题（九套 / 自定义种子色）
范围=仅卡片 ? 壁纸只做卡片背景 + 派生卡片色，不影响全局色
```
对比度：深/浅/高饱和/渐变壁纸下图表色阶可辨（FreshPaletteContrastTest 扩到壁纸极端色）；切换无闪色（色板切换用短 Crossfade 于色板层、不重建内容分支）。

## 8. 数据状态与采集链路（现状基础）

已有：三态空态（DataEmptyState：无记录/采集中/降级通道提示）、`hasAnyRecord`/`hasDataIn` 区分、`pull_log` 推导 GAP 日、事件三态（有记录/窗口外/缺口）。
**目标（阶段 E）**：八态（正常/采集中/部分/未授权/暂无记录/过期/失败/服务不可用）；主页面轻量行（状态 + 最近更新 + 采集方式）+ 设置页诊断页；权限撤销检测（生命周期恢复时校验 Shizuku/UsageStats 状态）。
