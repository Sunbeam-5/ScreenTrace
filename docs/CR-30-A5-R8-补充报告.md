## 1. supportedModes 重复 ID 处理规则（交付 9，明确说明）

**规则**：解析 supportedModes 时保留**原始模式条目列表**（`mode_entries`，(id, fps) 对），
**不转 dict、不 set 去重**（dict 会静默覆盖重复 id——正是本 P1 缺陷）。判定：

1. 统计每个 mode id 的出现次数（`device_modeId_counts`）。
2. **目标活动 mode id 必须恰好出现一次**：
   - 出现 **0 次** → 映射缺失 → **无法确认（INVALID，零点击）**；
   - 出现 **≥2 次** → 映射非唯一 → **INVALID，零点击**——**即使重复条目 fps 完全相同亦不放行**；
   - 恰好 1 次 → 取该唯一条目的 fps 作为 `actual_active_display_fps`。
3. **非活动 id 的重复不影响判定**（活动 id 唯一即可），但**如实记录**：
   `duplicate_mode_ids`（重复 id→次数）、`device_mode_entries`（原始条目含重复）、
   `active_mode_id_occurrences`、无法确认时的 `reason`（含重复条目 fps 列表）。
4. 唯一性校验**先于** fps 得出——只有校验通过才写 `active_mode_fps`。
