## 1. P1 修复：mActiveModeId 设备绑定

原缺陷：`re.search(r"mActiveModeId=(\S+)", text)` 全局取第一个，可能命中其他显示设备；
active_id 缺失时仍可能用 modeId 返回 fps。

现规则（`parse_display_refresh`）：
1. 以 `DisplayDeviceInfo{` 分段，每段归属其前方设备；**uniqueId 必须存在且非空**，否则无法确认。
2. 目标内置屏（type INTERNAL/内置屏幕）必须唯一；**外接/虚拟屏字段不得补全内置屏**。
3. `mActiveModeId` **只从目标设备自己的分段读取**，必须恰好一个；全局存在无法归属任何
   设备段的 mActiveModeId（孤儿）→ 无法确认（缺失/多值/归属不明同）。
4. 目标设备 `modeId` 与**自身** `mActiveModeId` 必须一致；活动模式 id 必须在**该设备自身**
   `supportedModes` 中唯一映射（不同设备同 id 不同 fps 时各用各的映射）。
5. 任一不满足 → actual=None → INVALID、零点击。
